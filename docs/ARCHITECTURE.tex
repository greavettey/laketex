\begin{abstract}
This whitepaper specifies the internal architecture of Laketex, detailing the pure-Rust typesetting pipeline, lexer tokenization, AST layout engine, multi-threaded debounced compiler worker, and PDFium rasterization integration.
\end{abstract}

\section{System Architecture Overview}

Laketex is structured as a collection of decoupled, memory-safe Rust crates and modules:
\begin{itemize}
    \item \textbf{\texttt{document}}: In-memory document model, incremental lexer, and AST outline parser.
    \item \textbf{\texttt{engine}}: The native typesetting engine featuring the AST parser, layout geometry calculator, math formula renderer, and vector PDF exporter.
    \item \textbf{\texttt{compiler}}: Multi-backend orchestrator interfacing with the native typesetter, Tectonic, and traditional \TeX\ engines.
    \item \textbf{\texttt{viewer}}: Dual-mode vector canvas and dynamic PDFium renderer.
    \item \textbf{\texttt{ui}}: Graphical interface built on \texttt{eframe} and \texttt{egui}.
    \item \textbf{\texttt{headless}}: Headless CLI dispatcher and HTTP REST API daemon.
\end{itemize}

\section{Native Typesetting Pipeline}

Unlike wrapper applications that depend on external \TeX\ binaries, Laketex includes a native typesetting engine written in 100\% safe Rust:
\begin{enumerate}
    \item \textbf{Tokenization}: \texttt{LatexLexer} scans input source code into typed tokens (commands, math spans, environments, text).
    \item \textbf{AST Construction}: \texttt{NativeLatexParser} produces a structured \texttt{LatexAst} tree containing document metadata, sections, paragraphs, tables, equations, and code listings.
    \item \textbf{Layout \& Page Breaking}: \texttt{DocumentLayout} computes font metrics, word wrapping, margins, and page division into \texttt{TypesetPage} structs.
    \item \textbf{Vector PDF Export}: \texttt{NativePdfExporter} generates clean, compliant PDF byte streams in $< 75\text{ ms}$.
\end{enumerate}

\section{Tectonic \& Auto-CTAN Integration}

When compiling with the Tectonic backend, Laketex communicates with the embedded Tectonic binary. Tectonic utilizes an internal XeTeX engine paired with an HTTP resource provider that dynamically fetches required macro packages from CTAN repositories into a local cache directory.

\section{Safety \& Zero-Dependency Guarantee}

Laketex adheres strictly to safe Rust programming standards:
\begin{itemize}
    \item Zero \texttt{unsafe} blocks in the entire application codebase.
    \item No external C/C++ build dependencies; compiles cleanly using standard \texttt{cargo build}.
    \item Completely self-contained portable executable.
\end{itemize}
